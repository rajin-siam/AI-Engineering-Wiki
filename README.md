

> [!abstract] Purpose  
> This wiki is my personal learning and reference material for **AI Engineering**. It is designed to build knowledge gradually, starting from the fundamentals and progressing toward advanced AI systems and infrastructure.

The goal is to understand not only individual AI concepts, but also how they connect together and how they are used to build real-world AI systems.

---

## Wiki Structure

The wiki is organized into phases. Each phase has its own folder and a dedicated index page containing the topics covered in that phase.

```text
AI Engineering/
│
├── 01 — Foundations/
├── 02 — Machine Learning Fundamentals/
├── 03 — Neural Networks/
├── 04 — Tensors/
├── 05 — Deep Learning Frameworks/
├── 06 — Computer Hardware for AI/
├── 07 — How AI Runs on Hardware/
├── 08 — Deep Learning Models/
├── 09 — Foundation Models/
├── 10 — Generative AI/
├── 11 — AI Application Engineering/
├── 12 — LLM Engineering/
└── 13 — Advanced AI Engineering/
```

Each folder contains:

```text
Phase/
│
├── Phase Index
│
├── Topic 1
├── Topic 2
├── Topic 3
└── ...
```

The **Master page** provides the overall structure of the wiki.

The **Phase page** provides the learning path for that phase.

The **Topic pages** contain the actual explanations, examples, diagrams, and notes.

---

## Learning Approach

The content is designed to progress from **simple concepts to more advanced concepts**. Topics should be understood before moving deeper into the systems that depend on them.

The wiki can be expanded over time as new concepts, examples, and deeper explanations become necessary.
